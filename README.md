## SQL-Restaurant_Operations_Analysis

### Project Overview:
Restaurant Operations Analysis is a SQL-based data analysis project focused on understanding customer ordering behavior and menu performance for a fictional restaurant, Taste of the World Café.

The project follows a question-and-answer approach, using data from the menu_items and order_details tables to analyze menu performance, customer preferences, and ordering patterns.

### Project Objective:
- Explore the menu items and understand the available offerings.
- Analyze order details to understand customer purchasing behavior.
- Identify best- and worst-performing menu items.
- Analyze customer ordering patterns and preferences.
- Answer business questions using SQL queries.

### Data set:
Maven Analytics( Restaurant Operations Analysis)
<br>Number of Tables : 2
- `menu_items` — 32 rows
- `order_details` — 12,234 rows
